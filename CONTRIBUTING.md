# Contributing

1. Fork the repository and create a focused branch.
2. Keep credentials out of source control.
3. Add or update tests for behavior changes.
4. Keep documentation bilingual: English first, Traditional Chinese second.
5. Describe the user impact, tests, and deployment changes in the pull request.

Please keep each pull request small enough to review and preserve the rule that AI answers must be grounded in retrieved API data.

## LangChain changes

Keep Project 3 independent. Test planning, signed receipts and summary behavior together. Update its bilingual API/deployment/evidence guides when behavior changes. Do not commit deployment state, generated snapshots, raw traces or credentials. A documentation update does not authorize deploying the original sites.

# 貢獻指南

1. Fork 本倉庫並建立單一目的的分支。
2. 不得將任何金鑰提交至版本控制。
3. 行為變更需同步新增或更新測試。
4. 說明文件採雙語：英文在前、繁體中文在後。
5. Pull Request 應說明使用者影響、測試結果與部署變更。

每個 Pull Request 請維持可審查的範圍，並保留「AI 回答必須以實際取得的 API 資料為依據」原則。

## LangChain 變更

維持第三專案獨立，規劃、簽章收據與摘要行為須一起測試。行為改變時同步更新雙語 API／部署／成果指南，不提交部署狀態、產生的快照、原始追蹤或憑證。文件更新不等於授權部署原站。
